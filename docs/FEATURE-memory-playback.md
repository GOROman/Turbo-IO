# 機能仕様: 記憶の再生（Memory Playback）

Fork: GOROman/Turbo-IO / 前提: 眼鏡側 CFW は使わない（原廠ファーム + スマホ側機能のみ）

## 目的
録音の文字起こしを「日付」で読み返せるようにする。例：昨日の会話をグラス/スマホで再生し、記憶の補助にする。

## データソース（V1 アプリ内に既にあるもの）
- LocalArchiveController（録音アーカイブ：録音 + ローカル Markdown 文字起こし、検証済みコピー）
- ConversationTimeline（アプリ内会話のタイムライン、日時付き）
- GlassesRecordingInbox（グラスからの録音受信）
- ManualRecordingASR（手動トリガーの文字起こし。本文は端末内が原則）

## 画面と操作（案）
- 入口：「記憶の再生」ビューをツール/アーカイブに追加
- 日付ピッカー（デフォルトは昨日）。その日の録音・会話を時系列タイムラインで一覧
- 先頭に LLM 要約カード（その日の要点3つ、登場した人、決まったこと）— 生成は任意・手動実行
- 項目タップで全文表示。キーワード検索（日をまたいで検索も可）
- 再生方法（CFW なしで可能な範囲）:
  - グラスの会話表示 / プロンプター表示へ本文を流す（既存の送信経路を流用）
  - スマホ TTS で読み上げ（速度調整可）
- プライバシー：文字起こしは端末内保持が原則。クラウド送信は既存の手動 ASR と同じく明示操作時のみ

## 将来拡張
- reSpeaker Clip の文字起こし（Mac Studio 側に蓄積）も、Mac 側ブリッジ経由で同じ「記憶の再生」に合流させる
- 実績ログカレンダーとの連携（その日の出来事として登録）

## 実装ステップ（案）
1. アーカイブ/タイムラインを日付で引く読み取りモデルを作る（既存データの再利用、新規保存形式は作らない）
2. 日付ビュー + 全文表示 + 検索
3. グラス表示送信と TTS 再生
4. 要約カード（任意実行）
